# 台股波段看板｜公開免費版 V3-Free

## 開始使用

需要 Python 3.10 以上。解壓縮後，在本資料夾開啟終端機：

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

瀏覽器開啟終端機顯示的本機網址。所有必要行情資料只來自 `www.twse.com.tw` 與 `openapi.twse.com.tw`，不使用FinMind，不需帳號、token、訂閱或手動證據CSV。Python套件由公開套件庫安裝。

**目前範圍為上市普通股與上市ETF，未接入上櫃/興櫃。** 未回測，分數不是勝率，也不保證獲利。這是可執行的研究工具，不自動下單。

## 三區功能

1. 輸入上市股票/ETF完整中文簡稱或代碼，提供最近三個交易日分數、平均分、迷你折線圖、升降溫狀態與分項。
2. 直接讀證交所首頁市值榜原始20筆，保留原順序、原名次、市值（億元）及排名日；不自行重算、不補名額。ETF移出後第二區可能少於20筆。
3. 定期定額交易戶數排行前15 ETF，加上市值榜移入ETF，按代碼去重，保留雙重入選來源及各自名次。總數可能多於15，不刪除額外移入ETF。ETF全部使用同一個獨立公式。

同一ETF出現在兩榜中只計算一次。按「更新第二區與第三區」完成分流及兩區計算；也可以只更新第三區。第三區與個股分數不可直接比較。

所有三日圖固定0–100分縱軸。圖中從左到右是前兩交易日、前一交易日、最新評分日。表格保留日期序列及分數序列，滑鼠可查看迷你圖數值，展開詳情可看帶日期的圖表。可下載結果與分項CSV。

- 三日最高最低差≤2分：⚪持平。
- 非持平且兩段變化均不下降：🔴持續升溫。
- 非持平且兩段變化均不上升：🔵持續降溫。
- 其他情況，最後一天上升為🟠回升；否則為🟣回落。

## 免費版的公式調整：八面向都計算，不沿用缺項V2

八面向各0–100分，各有四項條件，每符合一項25分。

`S = .10M + .15I + .23F + .05V + .22T + .10L + .05H + .10R`

為了讓免帳號官方資料能自動計算，本版明確調整了F、V、H、R的子條件，不宣稱與先前提議的歷史五年估值、三月營收加速等原公式完全相同。

| 面向 | 權重 | 四項條件 |
|---|---:|---|
| M 大盤 | 10% | 加權指數高於MA60；MA20高於MA60；MA60高於20交易日前；有效上市公司樣本超過50%高於MA60 |
| I 產業 | 15% | 排除自身的同業20日報酬中位數優於加權；60日報酬中位數優於加權；同業超過50%高於MA60；同業60日報酬中位數為正 |
| F 營運 | 23% | 最新月營收年增為正；今年累計營收年增為正；當月年增高於累計年增；最新營業利益率為正（金融保險業固定改看基本EPS為正） |
| V 估值 | 5% | 有效正值P/E低於同業中位數、25百分位；有效正值P/B低於同業中位數、25百分位。金融業、虧損/本益比不適用者固定改用P/B比較同業75/50/25/10百分位，各25分 |
| T 趨勢 | 22% | 比較價高於MA60；MA20高於MA60；60日相對加權報酬較高；離MA20不超過2ATR |
| L 量能 | 10% | 20日均成交額≥1億元；5日均成交額≥20日；20日上漲日均量大於下跌日；20日每天都有成交 |
| H 籌碼 | 5% | 外資20日買超；投信20日買超；合計近5日買超；合計20日淨買超股數/20日成交股數≥1%。不再依賴融資資料 |
| R 風報 | 10% | 扣成本RR≥2；RR≥3；停損距離≤2ATR；停損距離≤買價8%。若無合理上方目標或停損則整個R=0，而非缺項 |

M與I採有效資料樣本，市場廣度最少300家、同業行情最少3家，明細列樣本數。官方產業分類較粗，並不保證同業商業模式完全可比；不跨產業硬湊。估值資料無法適用、同業有效P/B不足3家時，該股報錯，不以假分數補齊。

F使用最新營收與營益彙總表；營益表可能是累計期間，不稱為單季年增。金融保險業使用其業別官方損益表基本EPS，並不直接套一般業營業利益率。

V使用最新同業估值橫截面，**沒有五年歷史估值分位**。不是券商預估EPS或目標價。虧損公司低P/B並不保證低估。

### R的可重現價位規則

以評分日收盤價作為假設進場價P：

- 停損參考價：此前20個交易日最低價，減0.5×ATR14。
- 目標參考價：此前60個交易日最高價。
- 若前高不高於現價，表示本規則找不到可用上方目標，R=0，不為新高股票虛構更高目標。
- 比較價先換算到評分日原始價格尺度，再計算可交易的價位。
- 示範成本：買賣手續費各0.1425%、股票賣出稅0.3%、往返滑價合計0.1%，皆按進場價估算，屬保守簡化假設，實際費率可改 `stock_score` 的cost公式；未精算賣出價差異。
- `RR = (目標-P-預估往返成本) / (P-停損+預估往返成本)`。

這是技術目標與示範風控，不是保證成交的停損單，也不是券商目標價。需要自己核對股價跳動單位、流動性與交易成本。

### 個股門檻

未持有：低於70不進場，70–<80觀察，80–<85試單候選，85–<90分批建倉候選，90以上完整建倉候選。

80以上仍要M≥50、F/T/R各≥75，否則顯示「高分但未通過必要條件」。持有狀態另列續抱檢查、減碼或退出評估；停損與交易理由失效優先。沒有你的資金與持股資料，所以不計算個人實際加碼股數。

**新子條件會改變分數分布；以上門檻只是原始規則的延續，尚未回測或校準。**

## ETF公式

`ETF分 = 趨勢40% + 動能25% + 量能20% + 價格穩定15%`。

每面向四條件，每條25分：

- 趨勢：價格>MA20、價格>MA60、MA20>MA60、MA60高於20交易日前。
- 動能：20日報酬>0、60日報酬>0、價格高於20日與60日中位數。
- 量能：20日均成交額≥1億元、≥5億元、5日均成交額≥20日、上漲日均量>下跌日。
- 價格穩定：ATR14/價格依序≤4%、3%、2%、1%。

未評估淨值折溢價、追蹤誤差、匯率、久期、信用與槓反每日重設。不能把個股80分門檻套在ETF上。

## 日期與三日分數的重要定義

1. 收盤行情與法人按三個日期各自截取，不用未來行情。
2. **F、V及公司分類採本次取得的最新公開快照，固定用於三日重估。三日圖不是當時已知資訊的點時回測。** 例如今天才發布的財報可能影響三天的重估分；程式不宣稱它三天前已公開。這是免費且不需逐檔找歷史公告時點的明示取捨。
3. 若要嚴格比較每天當時的完整分數，需每日保存快照並累積後再另做版本，不能由本版的重估序列冒充。
4. 官方估值快照不會隨重估日股價回算；因此V三日可能完全相同。F也通常相同。原始營收年月、財報年度季別、出表日期、估值資料日、取得時間均可查看。
5. 官網首頁榜僅最新快照。第二、三區選過去日期早於最新排名日會拒絕；不把今天的名單當歷史選股回測。
6. 當天21:00以前不使用今天作完整評分日。若來源尚未發布，會提示失敗，不任意把不同日期資料拼成當日總分。
7. 沒有把缺資料、停牌或新上市歷史不足的標的補成0分。正常可取得資料時會自動計算全部八面向；無法取得時列具體錯誤，不要求手填證據。

### 比較價的建法與限制

官方日行情有收盤價與漲跌價差，由此得到當日開盤競價參考價：`reference = close - signed_change`。

比較價依 `close/reference` 的連乘序列重建，消除以參考價重設造成的價格斷點，OHLC按比例映射；最後換回評分日原始價尺度。**它不是官方供應的還原股價，也不是現金股利再投資總報酬序列。** 參考價可能受特殊交易制度影響；停牌、無效參考價或特殊公司行動可能使該股無法評分，不能視為所有情境都已完整還原。市場比較指數使用加權價格指數，兩者口徑亦非完全一致。

## 快取、限速、初次等待

- 全市場一次抓一個交易日，所有股票共用；一次建立85個市場交易日，不是每檔抓85次。
- 另抓22個交易日法人資料，涵蓋三個評分日各自20日窗口。
- 初次約需30–60分鐘（來源速度不同），按鈕後顯示進度。保留視窗等待。之後主要讀本機快取。
- 每次網路請求最少間隔15秒；同資料夾跨程序鎖；每台本機資料夾每日最多200次。
- 401/402/403/429後停止所有請求並冷卻24小時；5xx冷卻15分鐘；連線失敗不自動重試。沒有代理IP輪換、身份偽裝或繞過驗證。
- 建立到一半中斷可再按按鈕，已成功資料會命中快取；不要刪掉cache來規避來源限制。
- 最近7日行情快取6小時、較舊行情30天、公開快照與法人通常24小時；首頁榜6小時。離線可讀已過期快取，介面會顯示原始擷取時間與離線標記。
- 不保證IP永遠不被限制；同IP其他使用者流量、來源政策及服務狀態不由本程式控制。
- 請保持cache資料夾，不要公開部署未加存取控制的多人版本。
